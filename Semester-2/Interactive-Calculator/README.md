# Interactive Calculator (C++)

A menu-driven calculator built in C++ using conditional logic (if-else and switch), functions, and input validation.

## Features
- Addition, Subtraction, Multiplication, Division
- Square Root
- Exponentiation (Power)
- Remainder (Modulo)
- Absolute Value
- Reuse the previous result in the next calculation
- Input validation and error handling (invalid input, division by zero, square root of a negative number)

## How to Compile and Run
```
g++ calculator.cpp -o calculator
./calculator
```

## Sample Output
```
Please select an operation:
1. Addition
2. Subtraction
...
Enter your choice (1-9): 1
Enter first number: 12
Enter second number: 8
Result: 12.0000 + 8.0000 = 20.0000
```

## Concepts Practiced
- Conditional statements (if-else, switch)
- Functions and code reuse
- Input validation with `cin.clear()` and `cin.ignore()`
- Loops for a menu-driven program
