# Bank Account System

A console-based banking system written in C++.

## Features
- Create savings/checking accounts
- Deposit and withdraw money
- Interest calculation (3% savings, 1% checking)
- Currency conversion (USD, EUR, JPY)
- Display all accounts
- Boundary condition testing

## Concepts Used
Structs, vectors, functions, pass-by-reference, pointers, input validation

## How to Run
```
g++ Add_Bank_Account_System.cpp -o bank
./bank
```
